Published instrument · v0

Agent card / identity-assertion conformance — an openly reproducible corpus

Per-test criteria, expected verdicts, committed fixtures, a frozen digest, and one recompute command a stranger can run with no membership, no shared table, and no trust in the issuer.

What this is

A published set of named conformance tests for agent cards and identity assertions: is this signed assertion well-formed, correctly canonicalized, and verifiable against a pinned anchor?

This is the reproducibility demonstration. A corpus for deployed-agent authority-adherence under adversarial pressure — whether an agent stays inside its declared authority — is the next, net-new build, and is not what ships here. Every test states its criteria and its expected verdict in public.

What makes the verdict checkable

  • Every arm is named, with its expected verdict published beside it.
  • The fixtures are committed, so each arm's input is public.
  • A frozen digest pins the exact bytes the verdict was computed over.
  • One command recomputes digest and verdicts from a fresh copy — no membership, no key store, no shared table.
  • Two independent checks ride inside the instrument: published cryptography vectors (RFC 8032) and published canonicalization vectors (RFC 8785), so correctness is measured against an external reference rather than our own expectations.

Recompute it yourself

git clone <release-url> && cd agent-accreditation-corpus-v0
python3 card-verify/verify_fixture.py          # 13/13 arms as expected
python3 card-verify/oracle/verify_oracle.py    # 29/29, exit 0

What this is not

This is not a certification, not a mark, not an accreditation, and not an assurance opinion. It publishes criteria and expected verdicts. It certifies nothing and no party's conformance. See the front-matter in card-verify/CORPUS-v0.md §1.
